Scaled results

One pipeline from both branches: diverse PhysX scenes and tasks, open reviewers and proposers measured against GPT-5.4 and PhysX, and state predictors judged in both spaces.

The same loop, at scale

The end-to-end study ran at small scale. Here the pipelines of both lines of work are merged and run on close to a thousand simulated scenes from twelve families, including trials converted from the Kubric MOVi and Physion datasets, with over 300,000 PhysX rollouts. The questions: which open models can write tasks or review outcomes in place of GPT-5.4, and which state-predictor architecture, training objective and amount of data predicts motion best.

PhysX (Isaac Sim 6.1, 1920 Hz, 3 s rollouts) is the ground truth throughout. Success is decided by deterministic checks on a trajectory; the same checks run on a predictor's trajectory, so every action has a verdict in both spaces.

Status (14 Oct 2026, 12:08): test set frozen (418 tasks); predictor sweeps done on clean data; reviewer study, pretraining on MOVi / Physion and Stage 2 planning running. Sections fill in as runs finish.

PhysX
the physics engine inside NVIDIA Isaac Sim 6.1, run at 1920 steps per second; the ground truth on this page.
Rollout
one 3 s simulation of a scene after an action, recorded at 30 frames per second (positions, rotations, velocities, contacts).
Task
an instruction plus machine-checkable success conditions (e.g. 'the ball ends inside the bin and never touches the vase').
Checks / verdict
the task's conditions evaluated on a trajectory by code (no LLM); verdict = success or failure.
Difficulty
share of 24 random actions that succeed in PhysX: easy >= 20%, medium >= 8%, hard > 0%, very hard = only found by refining near misses.
Passive start
a scene that starts with objects already moving (Physion pushes, MOVi tosses) instead of at rest.
PhysX screen
a rollout is used only if the solver stayed sane: no deep interpenetration, no energy gain, nothing leaves the world.
State predictor
a learned model that, given the scene and the action, predicts all objects' states for the next 3 s (a learned simulator).
Regression
predictor trained to output the future states directly (one forward pass).
Flow matching
generative predictor that turns random noise into a trajectory in 50 small steps; trained at random noise levels t.
τ uniform / logit-normal
how flow matching samples the noise level t during training: evenly over [0, 1], or concentrated around the middle.
DDPM
classic denoising diffusion (predicts the added noise).
Diffusion forcing
diffusion where each time chunk has its own noise level, so earlier frames are cleaner than later ones.
JEPA
predictor trained to match the future in a learned feature space, with a decoder back to states.
Width × depth
transformer size: hidden size × number of layers.
Conditioning (AdaLN / additive)
how the noise level enters the network: AdaLN = it scales and shifts every layer's normalisation; additive = it is added to the inputs once.
Patch
number of consecutive frames (1/30 s each) merged into one time token.
Tokens (rich / compact, +parts)
how each object is described to the model: rich = 69 numbers (shape, pose, size, mass, friction, bounce, inertia, joints, velocity); compact = 25; +parts = each object's convex pieces encoded separately.
ADE moving
average displacement error: distance between predicted and PhysX positions, averaged over all 90 frames and all objects that move (metres).
FDE moving
final displacement error: the same distance at 3 s only.
ADE acted
ADE of the object the action was applied to.
ADE hit objects
ADE of objects that were not acted on but moved (they were hit).
Still drift
how far the model moves objects that PhysX keeps still (metres at 3 s).
Contact F1
how well predicted contacts (which object touches which, per frame) match PhysX contacts; 1 = perfect.
κ (kappa)
Cohen's kappa: agreement corrected for chance; 0 = chance, 1 = perfect.
success@k
share of tasks solved within k PhysX attempts.
Valid
the written task parses, names real objects and uses allowed predicates and action types.
Non-trivial
doing nothing does not already satisfy the task.
Solvable
at least one of the tried actions succeeds in PhysX.
Its first choice
the candidate the proposer ranked first, executed in PhysX.
Random pick
expected success of picking one of the 8 candidates at random.
Predictor pick
the candidate the state predictor rates best, executed in PhysX (the headline: 8 candidates, 1 execution).
Any of 8
upper bound: some candidate succeeds in PhysX.
Agreement
share of rollouts where the two verdicts (reviewer or predictor vs PhysX checks) match.
Wrong success / wrong fail
verdicts that call a PhysX failure a success / a PhysX success a failure.
Preview
trying a candidate action in a simulator (PhysX or a predictor) before committing to one.

Key results

  • 939 PhysX scenes (473 test) and 333,740 3 s rollouts at 1920 Hz; 89% pass the PhysX sanity screen. 12 scene families, incl. MOVi-A / MOVi-B and Physion trials re-simulated from their recorded start states.
  • State predictors (79k training rollouts): regression and JEPA predict best (validation ADE 0.55-0.57 m, contact F1 0.49-0.52); flow matching 0.62-0.64 m; diffusion forcing 0.98 m; DDPM does not converge.
  • Flow time sampling: uniform beats logit-normal on both seeds (0.62-0.64 vs 0.71 m), so uniform is used.
  • Inputs: rich object tokens matter most (compact tokens +0.32 m); SE(2) augmentation -0.05 m; part encoder, contact head, separate action token and 60M vs 23M parameters change ADE by <= 0.03 m.

Setup

  • Isaac Sim 6.1 PhysX, TGS 16/4 iterations, CCD, enhanced determinism, 1920 Hz, 3 s recorded at 30 fps.
  • Success = deterministic predicate checks on the trajectory; the same checks run on predicted trajectories.
  • Predictors: one transformer backbone (23M unless noted), 50 Euler / sampling steps for generative objectives, scenes in validation and test are never seen in training.
