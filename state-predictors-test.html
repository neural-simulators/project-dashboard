State predictors on V2 test

The latest 200M state predictors on Dataset V2 simulations held out from their training, next to the physics engine; the same families and layout as the State predictors on V2 tab, with new held-out scenes. Updated 13 November 2026, 02:34 UTC.

In short

  1. 200M masked regression has the lowest median error on these clips, 0.07 m.
  2. Hardest families here: granular (0.64 m), orbital (0.50 m), balloon (0.47 m), domino branch (0.40 m). Easiest: crank (0.02 m), crate drop table (0.02 m), ramp spring domino (0.03 m), diving board (0.03 m).
  3. Every scene here is held out from the 200M training: a furnished test room or a test scene of Dataset V2 that no checkpoint trained on, and none of the scenes the State predictors on V2 tab already shows.
  4. Hidden action: given only the first and last state, 200M masked regression names the right kind of action in 93% of cases (balanced over kinds) and the right object in 97%; the force is off by 32% and the start time by 0.20 s.
  5. Hidden properties: watching the motion, 200M masked diffusion gets masses to a log ratio of 0.057 (guessing the average: 1.521); friction and restitution improve less (0.098 against 0.146, 0.093 against 0.155).
  6. Infilling is the weak spot: filling the middle of a motion, the best model (200M masked diffusion, 0.037 m) is close to straight interpolation between the given ends (0.042 m); 200M masked regression is worse than it.
  7. PhysX replays are the hard test: PhysX run with the true action or properties reproduces the recordings (median 0.000 m), but run with the models' inferred actions and properties it ends up 0.17 to 0.27 m from them (median over the replays): the estimates are close in number, not exact enough to reproduce the motion.

PhysX replays of the inferred actions and properties · the independent check: does running PhysX with the answer reproduce the recording?

The independent check of the inverse questions: PhysX is run again with what a model inferred, and the result is compared with the recording. These clips are rendered in the new paper look (path tracing, brighter lights; the Rendering preview tab); the other clips of this tab are still in the gallery look. A replay can never match exactly on another machine: PhysX repeats a run bit for bit only on the same processor and worker schedule, and chaotic scenes drift from rounding-size differences. So every record also gets two controls: PhysX run again with nothing changed (the floor any answer can reach), and the true values sent through the same path as an answer. Error: mean distance of the moving bodies from the recording over the whole clip. Only records that PhysX's CPU backend wrote are replayed (the backend that reproduces them best). No-action control not run: where the outcome hardly depends on the push (in cascade and catapult a weaker push still gives the same end), a near-zero replay error does not prove the right action.
