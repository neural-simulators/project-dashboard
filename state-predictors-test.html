How this was done · models, data and what the numbers mean
itemvalue
modelsthe 200M masked models of branch wm-scale2: regression, flow (clean head), diffusion, and flow trained with property noise; 150,000 updates on the final data (475,016 records), our anti-shake term and retrained fix, tool not given
datafinal data, scene-level split of 8 November (split_v2.json): test scenes only. Dataset V2's 4,209 test records sit in four held-out rooms (layout_v3_29, layout_v3_39, layout_v2_12, layout_v2_13) and in one held-out scene per family
questionforward prediction: the first frame, every property and the action given; the same sampling as the test scoring (10 steps, question seed 0)
errormean position error of the moving objects over the predicted frames, after the floor rule
small modelsnot shown here: the State predictors tabs' small models were trained on the simple set only, so these scenes are new to them too, but they have not been run on these records yet
